Патч с подключённым номером счётчика Яндекс.Метрики: 110517614.

События товаров:
- product_detail_click — клик «Подробнее»;
- product_card_open_click — клик по карточке/названию;
- product_buy_click — клик «Купить»;
- product_download_click — клик «Скачать»;
- product_page_view — открытие страницы товара.

После загрузки патча в Яндекс.Метрике можно создать цели типа «JavaScript-событие» с этими идентификаторами.
